# v0.9.4 — 제3차 유닛 정보 화면 글자 깨짐 수정 + 메뉴 띄어쓰기 정리

제3차의 **유닛 능력 화면에서 글자가 깨져 보이던 문제**를 고치고, 메뉴·상태
화면 전반에서 **일본어 원문보다 길어져 밀리거나 잘리던 한글 라벨의 띄어쓰기를
정리**했습니다. 제2차는 이번 변경 대상이 아닙니다(내용 동일).

## 무엇을 고쳤나

### 1. 유닛 능력 화면 '타입'·'실드' 주변 깨짐

유닛 능력 창의 지형 적응 열(`空`/`陸`/`海`/`宇`)은 **한 칸짜리 고정 셀**인데,
번역이 이를 두 글자 한글(`공중`/`육지`/`바다`/`우주`)로 채우고 있었습니다.
폭이 두 배가 되면서, 셀 경계를 넘어간 글리프가 옆 열(지형 등급·특수능력)의
픽셀을 침범해 **'타입' 글자와 '실드' 다음 글자가 동시에 깨져** 보였습니다.
렌더러의 `FC` 제어는 커서만 되돌릴 뿐 **이미 그려진 픽셀은 지우지 않기** 때문에
생긴 증상입니다.

이미 정상 동작하는 **제2차의 같은 화면을 기준**으로 삼아(제2차는 처음부터
`공`/`육`/`해`/`우` 한 글자), 제3차도 단일 음절로 맞춰 **레트일과 폭·위상이
바이트 단위로 동일**해졌습니다. 특수능력(`실드`) 칸 자체는 원래 정상이었고,
지형 열의 침범이 원인이었습니다.

### 2. 메뉴·상태 화면 띄어쓰기 정리

한글 번역에 넣은 띄어쓰기 때문에 **일본어 원문보다 넓어진 항목 488개**를
찾아 띄어쓰기를 제거했습니다. UI 레코드 107개와 이름·무기·지형 등 테이블
전체를 원문과 폭(advance) 단위로 대조해 후보를 찾고, 각 항목이 읽는 데
문제없는지 개별 검토를 거쳤습니다.

- **무기명** — `그레네이드 런처` → `그레네이드런처`, `메가 입자포` → `메가입자포`
- **유닛·인명** — `겟타 포세이돈` → `겟타포세이돈`, `마 쿠베` → `마쿠베`
- **지형·강화 파츠·특수능력** — `군사 기지` → `군사기지`, `오라 배리어` → `오라배리어`
- **메뉴 라벨** — `시스템 설정` → `시스템설정`, `성별 남자` → `성별남자`

**문장은 그대로 둡니다.** 정신 커맨드 설명, 시스템 메시지 등 실제 문장
(49개)과 문장 조각은 가독성을 위해 띄어쓰기를 유지했습니다. 탭 헤더처럼 여러
항목이 한 줄에 붙는 경우는 **항목 안쪽만** 붙이고 항목 사이 간격은 남겼습니다
(`유닛능력 파일럿능력 무기성능`).

## 검증

- 제3차 단독판 이식 후 **UI 레코드 107/107**, 테이블 3200개가 컴플리트 박스
  빌드와 **바이트 단위로 일치**함을 확인했습니다(나머지 24개는 레트일에서도
  쓰이지 않는 빈 슬롯).
- 단독판 이미지의 `3_SCE`·`BMESS3`·`3_DEAD`·`SLPS_025.30`을 **ISO 디렉터리를
  통해 되읽어** 의도한 파일과 일치함을 확인했습니다.
- 세 이미지 모두 xdelta 역적용(retail → 패치 결과) 재현을 통과했고, 배포용
  **간편 적용 zip을 실제로 실행**해 나온 이미지가 빌드본과 동일함을 확인했습니다.

## 적용

세 판 모두 **간편 적용 zip**(더블클릭)과 **xdelta**(수동), **별도 `.cue`** 를
제공합니다. 적용법은 v0.9.3과 동일합니다.

| 판 | 간편 적용 zip | 패치(xdelta) | .cue (별도) |
|----|---------------|--------------|-------------|
| **컴플리트 박스** (제2차 전체 + 제3차 전체) | `srwcb-cb-korean-v0.9.4-easy-apply.zip` | `srwcb-second-third-korean-v0.9.4.xdelta` | `srwcb-cb-korean-v0.9.4.cue` |
| **제3차 단독판** (SLPS-02530) | `srw3-standalone-korean-v0.9.4-easy-apply.zip` | `srw3-standalone-korean-v0.9.4.xdelta` | `srw3-standalone-korean-v0.9.4.cue` |
| **제2차 단독판** (SLPS-02406) | `srw2-standalone-korean-v0.9.4-easy-apply.zip` | `srw2-standalone-korean-v0.9.4.xdelta` | `srw2-standalone-korean-v0.9.4.cue` |

zip 을 풀고 원본을 넣은 뒤 **`한글패치 적용하기.bat`** 더블클릭하면 한글판
이미지와 `.cue` 가 자동으로 만들어집니다. 수동 적용(xdelta 직접)하시는 분은
위 별도 `.cue` 를 받아 패치된 이미지와 같은 폴더에 두고 여세요.

| 파일 | SHA-256 |
|------|---------|
| 패치 결과 CB Track 1 | `f721ea6f…e883` |
| 패치 결과 제3차 단독판 | `588225bf…0e01` |
| 패치 결과 제2차 단독판 | `1a14d915…2032` |

전체 자산 해시는 [`release/SHA256SUMS_v0.9.4.txt`](../release/SHA256SUMS_v0.9.4.txt)
에 있습니다.
