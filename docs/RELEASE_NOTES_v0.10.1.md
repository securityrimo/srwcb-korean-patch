# v0.10.1 — EX 화면 깨짐 수정 + 미번역 항목 보충

v0.10.0 실기 플레이에서 확인된 《슈퍼로봇대전 EX》의 화면 깨짐을 고치고, 주입기가
놓치고 있던 항목들을 추가로 한국어로 옮겼습니다. **제2차·제3차는 v0.9.4/v0.10.0과
바이트 단위로 동일**하며 이번 변경의 영향을 받지 않습니다.

## 고친 것

- **유닛 능력창 '타입' 칸 글자 깨짐** — 유닛 타입 테이블 15개 중 4개(陸/空/空/水陸)가
  일본어로 남아 한글 폰트에서 엉뚱한 글자로 나왔습니다. 이제 15개 전부 한국어입니다.
- **챕터 선택 화면 깨짐** — 한 줄이 전각 스페이서로 `[장 이름] [난도]` 두 칸으로
  나뉘는데, 번역이 이 구분자를 지워 두 칸이 하나로 합쳐지면서 글자가 칸 밖으로
  밀리고 겹쳤습니다. 구분자를 보존하고 칸마다 원본 폭에 맞췄습니다.
- **선택지 대사 겹침** — 선택지·메뉴 레코드는 창 폭이 일본어 원문 기준으로 잡히는데
  번역이 더 길어 글자가 뭉갰습니다. 해당 레코드를 원문 폭 안으로 다듬었습니다.
  (`마사키「아직 입이 살았군‥‥」/말없이 강타`, `얀롱(큭‥‥쓸데없는 참견)`,
  `마사키편(쉬움)/류네편(보통)/슈우편(어려움)` 등)
- **자동 줄바꿈으로 인한 글자 깨짐** — 사전 줄바꿈 없이 들어가 렌더러가 두 바이트
  글자 한가운데를 잘라 버리던 대사를 폭 안으로 맞췄습니다.

## 새로 한국어로 나오는 것

- **캐릭터 사전 · 로봇 대도감** — 등장 작품명, 데모 제목, BGM 제목 등 130여 항목
- **사운드 설정** 모노/입체, **有/無**
- **저장 확인**, **유닛 강화 확인**(이동력·HP·장갑·EN·운동성)

## 아직 남은 것

시나리오 예고편·오마케 컷신(69건)과 중단(전원 끄기) 메시지(13건)는 아직
일본어입니다. 이 두 묶음은 포인터 없이 순차로 읽히는 저장소라 저장소 전체를
재구성해야 하며, 다음 버전에서 다룹니다.

## 검증

- 자동 검증 6종 통과(글리프 순서 고정, UI 앵커 보존, 변경 범위, 스팬 폭/위상 드리프트,
  이미지 내 한글 렌더 96.7%, 제2차·제3차 무회귀)
- **제2차·제3차 회귀 없음** — `THIRD.WAR` · `SECOND.WAR` · `SLPS_020.70` · `3_SCE.BIN` ·
  `BMESS3.BIN` 다섯 영역이 v0.10.0과 바이트 단위로 동일
- EX 단독판 이식본이 컴플리트 박스판과 동일한 번역을 담고 있음을 문자열 단위로 대조
- 두 패치 모두 xdelta 역적용 재현, 배포용 easy-apply zip을 실제로 실행해 결과 해시 일치
