# v0.10.4 — 게임 선택 화면 글자 다시 그리기

기능은 v0.10.3 과 같고, **게임 선택 화면의 한글 글자를 더 읽기 좋게 다시 그렸습니다.**

## 무엇이 달라졌나

v0.10.3 의 글자는 원본의 "행마다 바뀌는 채움색"을 그대로 흉내 내다 보니 얼룩덜룩하고
윤곽이 흐릿했습니다. 원본을 다시 뜯어보니 그런 구조가 아니었습니다.

CLUT 은 `0=흰색`에서 `11=거의 검정`으로 이어지는 노랑 램프이고 `12`가 배경입니다.
원본 글리프를 침식 깊이로 분석하면

| 깊이 | 쓰이는 색 |
|------|-----------|
| 1 (테두리) | 5·6 (노랑), 그늘진 쪽에 9·11 |
| 2 | 0·1·2 (흰색~연노랑) |
| 3 이상 | 0 (흰색) |

즉 **흰 코어 + 노랑 테두리 + 우하단 그늘**이고, 검은 외곽선은 없습니다. 같은 규칙으로
한글을 다시 그렸습니다.

- 한글은 획이 가늘어 그냥 그리면 깊이가 1에서 끝나 '속 빈 윤곽선'이 됩니다.
  획을 1px 부풀려 최소 3px 을 만들어 흰 코어가 생기게 했습니다.
- 굵은 폰트(HANDotumB·맑은 고딕 Bold)는 이 크기에서 속공간이 막혀 뭉갭니다.
  레귤러 HANDotum 을 부풀리는 쪽이 훨씬 또렷해 그걸 씁니다.
- 기울기는 원본 이탤릭에 맞춰 유지하고, 네 항목의 글자 크기를 20px 로 통일했습니다.

## 검증

v0.10.3 과 동일한 게이트를 통과했습니다.

- 패치 전후 TIM 10개 목록 완전 동일, 지정 픽셀 범위 **밖 변경 0바이트**
- 21번 외 296개 멤버 바이트 동일, 표·파일 크기(9,932,026 B) 불변
