# v0.10.0 — 《슈퍼로봇대전 EX》 한글화 (컴플리트 박스 4개 타이틀 완주)

《슈퍼로봇대전 EX》(라 기아스편)를 **대사부터 메뉴·이름·시나리오 제목까지 전부**
한국어로 옮겼습니다. 이로써 컴플리트 박스에 수록된 **제2차 · 제3차 · EX** 가 모두
한글화되었고, **EX 단독판(별매 CD, SLPS-02529)** 도 함께 지원합니다.

## 무엇이 새로운가

- **시나리오 대사** — 마사키·류네·슈우 세 갈래의 라 기아스 이야기 전체
- **전투 대사** — 18,829건
- **격추 대사**, **시나리오 제목**, **지형·강화파츠·정신 커맨드·특수기능**
- **파일럿·기체 이름** — 얀롱·튜티·페일·카크스·사피네·모니카 등 EX 고유 인물 포함
- **맵/시스템 UI** — 턴 수·자금·페이즈 종료·부대표·반격 명령·시스템·저장
- **인터미션** — 데이터 저장·유닛 개조·무기 개조·갈아타기·강화 파츠·다음 맵으로
- **챕터 선택** — 마사키/류네/슈우의 장, 난이도, ISS 사용 여부

번역 단위 **8,493개**(제2차·제3차에서 재사용 2,395 + 신규 6,098)에 더해, 원장 추출이
놓친 레코드 **153개**를 별도로 찾아 보충했습니다. 이 레코드들은 한글 폰트에서
일본어가 깨진 글자로 보이기 때문에 반드시 처리해야 하는 부분입니다.

## 기술 노트

EX는 제3차와 엔진 구조가 사실상 같아(명령 메뉴·유닛 타입 테이블·시스템 메뉴 레코드가
**바이트 단위로 동일**) 기존 파이프라인을 오프셋만 바꿔 재사용했고, 검증된 번역을
그대로 이식했습니다. EX 고유의 차이도 몇 가지 있었습니다.

- **파일 로더** — 제3차와 달리 EX는 하드코딩된 파일-LBA 테이블이 없어(전수 스캔으로
  확인) 데이터 파일 재배치가 투명하게 반영됩니다.
- **BMESS4** — 인덱스 0이 빈 슬롯이라 아카이브 파서가 이를 보존하도록 고쳤습니다.
- **E_SCE 시나리오 68** — 마지막 레코드가 종결자 없이 풀 끝까지 이어져(제4차 예고
  광고) 꼬리로 보존하도록 처리했습니다.
- **배틀 스크래치** — 사용량이 한계 내라 제3차에서 필요했던 BSS 재배치가 불필요했습니다.

## 검증

- 폰트 글리프 순서 고정 — 기존 제2차·제3차 텍스트의 글리프 인덱스가 밀리지 않음
- UI 윈도우 앵커 보존, 도너 영역 안전성, 스팬 폭/위상 드리프트
- 이미지에서 데이터 파일을 되읽어 한글 렌더 확인(96.7%)
- **제2차·제3차 회귀 없음** — 두 게임의 실행파일·대사 아카이브 5개 영역이 v0.9.4와
  바이트 단위로 동일
- 두 패치 모두 xdelta 역적용(retail → 패치 결과) 재현, 배포용 간편 적용 zip을 실제로
  실행해 산출물 일치 확인

## 참고

- **제2차·제3차 단독판은 v0.9.4와 내용이 같습니다.** 버전만 맞춰 함께 올렸으니 이미
  적용하셨다면 다시 받지 않아도 됩니다.
- 이름 입력 화면의 가나 그리드는 일본어 입력용이라 그대로 둡니다.
- 시나리오 예고편 컷신 풀은 아직 미포함입니다.
- 처음부터 끝까지의 실기 완주 검증은 계속 진행 중입니다.
