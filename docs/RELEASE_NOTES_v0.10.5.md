# v0.10.5 — 트레이닝 모드 한글화 + 전투가 멈추던 문제 수정

컴플리트 박스의 네 번째 항목인 **트레이닝 모드**를 한국어로 바꾸고, 그 안에서
**전투가 진행되지 않던 문제**를 고쳤습니다. 제2차·제3차·EX 세 게임은 v0.10.4 와
완전히 동일합니다(바이트 단위로 확인).

## 전투가 멈추던 이유

트레이닝 모드에 들어가 전투를 시작하면 **대사가 한 줄도 나오지 않고 그대로
멈춰** 있었습니다. 원인은 전투 대사 아카이브의 **목차표**였습니다.

전투 대사는 `BMESS2/3/4.BIN` 에 들어 있고, 각 파일 맨 앞에는 어느 대사가 어디에
있는지 적은 1,600바이트짜리 표가 있습니다. 그런데 게임은 이 표를 파일에서 읽지
않고 **실행파일 안에 복사해 둔 사본**을 씁니다. 한글화하면서 세 아카이브를 다시
패킹했으니 사본도 같이 갱신해야 하는데, `SECOND.WAR` · `THIRD.WAR` · `EX.WAR`
세 개만 갱신하고 **`TR.WAR` 은 빠져 있었습니다.**

낡은 표를 들고 있으면 첫 전투 대사를 읽을 때 블록 한가운데를 가리키게 되고,
게임은 대사를 그리지 못한 채 다음 단계로 넘어가지 못합니다. 정확히 신고된
증상입니다. `TR.WAR` 안의 세 표(`0x103678` · `0x103CB8` · `0x1042F8`)를 재패킹본의
표로 교체해 해결했습니다.

## 트레이닝 모드 한글화

`TR.WAR` 은 EX 와 같은 엔진이라, UI 테이블 본문이 **헤더 4바이트만 빼면 EX 와
바이트까지 동일**하다는 걸 확인했습니다(레코드 3,282개 전수 대조). 그래서 EX
에서 이미 폭 검증을 통과한 번역을 그대로 재사용했습니다 — 새로 번역하며 폭이
어긋날 위험이 없습니다.

한국어로 바뀐 것:

| 항목 | 레코드 |
|------|--------|
| 지형 이름 | 131 |
| 정신기 (이름·설명) | 94 |
| 강화 파츠 | 46 |
| 무기 이름 | 530 |
| 파일럿 능력 | 52 |
| 기체 능력 | 22 |
| 시나리오 제목 | 191 |
| 파일럿 이름 (약칭·정식) | 396 |
| 기체 이름 | 139 |
| 메뉴·인터미션 (ui_master) | 104 레코드 / 364 span |
| 유닛 타입 (육·공·수·우주…) | 15 |
| 맵 UI 라벨 | 310 |
| 맵·시스템 창 (턴수·자금·페이즈 종료·방어/명중) | 5 |
| 그 밖의 잔여 레코드 (작품명·BGM 제목·확인 메시지 등) | 123 |

전투 대사는 위의 목차표 수정으로 `BMESS` 의 한국어 대사가 제대로 나옵니다.

트레이닝 모드의 시스템 설정창은 EX 와 한 군데 다릅니다 — '퀵 컨티뉴' 안내 두
줄이 없고, 시스템 메뉴 마지막 항목이 `세이브` 가 아니라 `종료` 입니다. 이 두
가지는 트레이닝 모드용으로 따로 맞췄습니다.

## 검증

- **오프셋 검증**: `TR.WAR` 의 테이블 12개 3,282 레코드를 EX 와 전부 대조해
  같은 자리인지 확인한 뒤에만 주입합니다. 상수 델타로 밀어 넣지 않습니다.
- **글리프 무결성**: 주입기는 폰트에서 쓰지 않는 글리프 슬롯을 레코드 저장소로
  재활용합니다. 최종 파일에서 거꾸로 훑어 **살아 있는 레코드가 그 슬롯을
  가리키지 않는지** 확인했습니다(과거 프리즈의 원인이던 유형).
- 테이블 포인터 3,282개 전부 유효한 레코드를 가리키고 종결자가 있음
- 반각 글리프(0x000~0x100) 영역 불변, PS-X EXE 헤더·파일 크기 불변
- 화면에 보이는 일본어 레코드 1,945 → 830 (남은 것은 EX·제2차와 같은
  시나리오 예고편/오마케 풀로, 트레이닝 모드에서는 나오지 않습니다)
- ISO 42개 파일 중 **`TR.WAR` 하나만** 달라짐, 섹터 583개 중 52개 갱신
- xdelta 역적용 재현, easy-apply zip 안의 해시 상수까지 대조
