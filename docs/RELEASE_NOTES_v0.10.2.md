# v0.10.2 — 부팅 게임 선택 화면 한글화 (그래픽 압축 코덱 해독)

디스크를 넣고 처음 만나는 **게임 선택 화면**이 한국어로 나옵니다.

```
  제2차 슈퍼로봇대전
  제3차 슈퍼로봇대전
  슈퍼로봇대전 EX
  트레이닝 모드
```

이 항목들은 텍스트가 아니라 **미리 그려 둔 그래픽**이라 지금까지 손댈 수 없었습니다.
이번에 게임의 **그래픽 압축 코덱을 역분석**해서 풀고, 한글로 다시 그린 뒤 같은 코덱으로
재압축해 넣었습니다.

## 기술 노트

- **압축 코덱** — `SLPS_020.70` RAM `0x8004e548` 의 LZ77 계열 디코더를 역분석했습니다.
  플래그 비트(MSB 우선) · 리터럴 · 13비트 오프셋 롱 매치(길이 3~9 또는 확장 2~256) ·
  8비트 오프셋 숏 매치(길이 2~5) 구조이고, 길이 바이트 0이 스트림 종료입니다.
  디코더와 **인코더를 모두** 구현했습니다.
- **자산 위치** — 메뉴 항목 4개는 `C_SMAP.BIN` 의 21번째 압축 멤버(해제 132,176바이트)
  안에 4bpp 인덱스 비트맵으로 들어 있습니다. 항목마다 크기가 달라
  184×20 / 184×20 / 156×20 / 184×19 이고 배경 인덱스는 12입니다.
- **원본 스타일 유지** — 원본은 행마다 채움색이 달라지는 세로 그라데이션에 검은
  외곽선입니다. 같은 규칙으로 한글을 그려 원본의 질감을 살렸습니다.
- **크기·오프셋 완전 보존** — 재압축 결과가 원본 멤버보다 988바이트 작아 원래 자리에
  그대로 넣었습니다. 파일 크기도 다른 296개 멤버의 위치도 1바이트도 바뀌지 않습니다.
  (개발 중 멤버가 127바이트 커져 뒤 멤버가 밀렸더니 타이틀 로고와 메뉴 창이
  사라졌습니다. 이 자산은 **섹터 위치에 민감**합니다.)

## 검증

- 해제 결과를 원본과 바이트 단위로 비교 — **메뉴 스트립 4개 밖은 변경 0바이트**
- 나머지 296개 멤버 전부 원본과 바이트 동일, 파일 크기 동일(9,932,026 B)
- 이미지에서 되읽어 재해제해 한글 픽셀 확인, ISO 섹터 4,850개 중 26개만 갱신
- 인코더 왕복 검증(압축→해제→원본 일치), xdelta 역적용 재현
- 배포용 easy-apply zip 을 실제로 실행해 결과 해시 일치 확인

제2차·제3차·EX 본편 데이터는 v0.10.1에서 달라진 것이 없습니다.

## 적용

| 판 | 간편 적용 zip | 패치(xdelta) |
|----|---------------|--------------|
| **컴플리트 박스** | `srwcb-cb-korean-v0.10.2-easy-apply.zip` | `srwcb-second-third-ex-korean-v0.10.2.xdelta` |
| **EX 단독판** (SLPS-02529) | `srwex-standalone-korean-v0.10.2-easy-apply.zip` | `srwex-standalone-korean-v0.10.2.xdelta` |
| **제3차 단독판** | v0.10.1과 동일 | `srw3-standalone-korean-v0.10.2.xdelta` |
| **제2차 단독판** | v0.10.1과 동일 | `srw2-standalone-korean-v0.10.2.xdelta` |

**단독판 3종은 v0.10.1과 내용이 같습니다.** 게임 선택 화면은 컴플리트 박스에만
있는 화면이라 단독판은 영향을 받지 않습니다.

## 남은 것

시나리오 예고편·오마케 컷신(69건)과 중단(전원 끄기) 메시지(13건)는 여전히
일본어입니다. 시나리오 예고 **타이틀 카드**(第2話 謀略の町 등)도 아직인데,
이번에 코덱을 풀었으니 같은 방법으로 다룰 수 있게 됐습니다.
