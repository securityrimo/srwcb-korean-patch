# v0.10.3 — 게임 선택 화면 수정 (v0.10.2 문제 해결)

**v0.10.2 를 쓰고 계시면 이 버전으로 교체하세요.** v0.10.2 는 게임 선택 화면에서
타이틀 로고와 메뉴 창이 사라지는 문제가 있었습니다.

## v0.10.2 에서 무엇이 잘못됐나

메뉴 항목 4개는 `C_SMAP.BIN` 21번 멤버 안에 **표준 TIM 이미지들이 줄줄이 이어 붙은**
구조로 들어 있습니다. v0.10.2 는 픽셀 영역의 시작 위치와 높이를 화면 캡처에서
역산해 잡았는데, 그 값이 실제 TIM 픽셀 블록과 어긋나 있었습니다. 그 결과 각 스트립을
그릴 때 **다음 TIM 의 헤더(매직 + CLUT)** 를 덮어썼고, 게임이 TIM 목록을 훑다가
그 지점에서 멈추면서 뒤따르는 메뉴 창·선택 화살표·타이틀 로고가 통째로 로드되지
않았습니다. 첫 항목만 한글로 보였던 이유입니다.

## 이번 수정

TIM 헤더를 직접 파싱해 픽셀 블록의 정확한 위치와 크기를 얻었습니다.

| 항목 | TIM | 크기 | 픽셀 범위 |
|------|-----|------|-----------|
| 제2차 슈퍼로봇대전 | `@85056` | 184×24 | 85120–87328 |
| 제3차 슈퍼로봇대전 | `@87328` | 184×24 | 87392–89600 |
| 슈퍼로봇대전 EX | `@89600` | 156×24 | 89664–91536 |
| 트레이닝 모드 | `@91536` | 184×24 | 91600–93808 |

빌드에 **TIM 무결성 게이트**를 넣었습니다. 패치 전후로 멤버 안의 TIM 10개 목록
(위치·비트깊이·크기·VRAM 좌표)이 완전히 같은지, 그리고 지정한 픽셀 범위 밖이
한 바이트라도 바뀌지 않았는지 확인하고, 어긋나면 빌드가 멈춥니다.

## 검증

- TIM 10개 목록 패치 전후 **완전 동일**
- 해제 결과에서 **스트립 4개 밖 변경 0바이트**
- 21번 외 296개 멤버 바이트 동일, 표·파일 크기(9,932,026 B) 불변
- 이미지에서 되읽어 재해제 확인, ISO 섹터 4,850개 중 26개만 갱신
- xdelta 역적용 재현, easy-apply zip 실제 실행해 결과 해시 일치
